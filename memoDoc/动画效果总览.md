# 🎨 首页动画效果总览

## 已集成的动画库

### 1. **Framer Motion**  主要动画库
- React 声明式动画库
- 提供丰富的手势和滚动动画
- 支持弹簧物理动画

### 2. **GSAP (GreenSock)** 🚀 专业级动画
- 业界最强的动画库
- ScrollTrigger 插件实现滚动动画
- 适合复杂时间轴动画

### 3. **CSS Animations** 🎭 轻量级动画
- 自定义关键帧动画
- 浮动、发光、闪烁效果

##  CSS 动画效果

### 🌊 浮动动画 (float)
```css
@keyframes float {
  0%, 100%: translateY(0) rotate(0deg)
  33%: translateY(-20px) rotate(2deg)
  66%: translateY(10px) rotate(-2deg)
}
```

### ✨ 发光动画 (glow)
```css
@keyframes glow {
  0%, 100%: box-shadow 20px
  50%: box-shadow 40px + 60px
}
```

###  闪烁动画 (shimmer)
```css
@keyframes shimmer {
  0%: background-position -200%
  100%: background-position 200%
}
```

##  动画特性

### ✅ 性能优化
- 使用 `whileInView` 仅在可见时触发动画
- `viewport={{once: true}}` 避免重复动画
- CSS `will-change` 优化渲染

### ✅ 用户体验
- 尊重 `prefers-reduced-motion` 设置
- 所有动画都有合理延迟
- 弹簧物理效果更自然

### ✅ 响应式
- 移动端自动调整动画参数
- 小屏幕减少复杂动画
