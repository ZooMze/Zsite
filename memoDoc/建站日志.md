## 2026-06-04 - backdrop-filter 构建丢失问题排查

### 问题现象
部署后导航栏毛玻璃模糊效果丢失，查看构建后的 CSS，只保留了 `-webkit-backdrop-filter`，标准属性 `backdrop-filter` 被移除。

### 根因
**在已配置 autoprefixer 的项目中，源码里手写了 `-webkit-backdrop-filter` 前缀。** autoprefixer 发现属性已存在前缀版本，跳过了对该属性的处理，导致标准属性被吞。

### 解决
删除所有手写的 `-webkit-` 前缀，只保留标准属性，让 autoprefixer 自动处理：
```css
/* ❌ 手写前缀与 autoprefixer 冲突 */
backdrop-filter: blur(12px);
-webkit-backdrop-filter: blur(12px);

/* ✅ 只写标准，自动生成前缀 */
backdrop-filter: blur(12px);
```

### 教训
工具各司其职。项目已配 autoprefixer → 不手写任何前缀。同时清理了 `home-route-overrides.css` 和 `memo-route-overrides.css`。
